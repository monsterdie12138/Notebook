    Uniform Spatial Partitions (Grids)

    Preprocess -Build Acceleration Grid:

    • 先对场景构建包围盒
    • 将包围盒划分为均匀的网格
    • 判断哪些格子里面有物体（表面）

    Ray-Scene Intersection:

    预处理后，我们就知道哪些格子有物体表面。

    现在有一条光线，遇到的情况：

    • 空格子：什么都不做
    • 有物体表面的格子：看一看是否与里面的物体相交
    • 不相交：什么都不做
    • 相交：

    因此，原本我们要和场景中所有三角形网格求交，现在，我们只需要看光线路径上有哪些格子，对于里面有物体的格子求交就行了。

    在一个格子结束之后，下一个格子是什么？例如往右上方，只要继续判断右边或者上边的格子就行（与格子求交）。有特定的算法，不做赘述。

    场景分布不均匀的时候用这个方法不太好，因为可能走太多空气格子。

    Spatial Partitions

    稀疏的地方是不是不需要用那么多格子？

    • Oct-Tree: 立方体均匀切成八个小立方体，递归进行，直到达到某个标准。
    • KD-Tree：二维：横着切、竖着切交替进行；三维：沿x切、沿y切、沿z切交替进行
    • BSP-Tree：不是横平竖直地切

    我们主要使用KD-Tree。

    KD-Tree Pre-Processing:

    在我们做光追之前，给定一个场景，先建立KD-Tree。

    Data Structure for KD-Tree:

    只需要在叶子节点存储实际的几何形体。

    Object Partitions & Bounding Volume Hierarchy (BVH)

    我们从物体考虑划分，而不是从空间考虑划分。应用更广泛。

    BVH:

    同样地，先用大盒子把所有物体框起来，然后把物体分组分成两部分，重新求各自的包围盒；继续划分一直到某个标准为止。

    因此其与KD-Tree不同，先划分物体，再求包围盒。因此一个物体只有可能出现在一个包围盒里。

    然而，BVH的包围盒是可以相交的，好的划分，包围盒重叠的少。怎么划分很有讲究。

    步骤：

    • find bounding box
    • recursively split set of objects in two subsets
    • recompute the bounding box of the subsets
    • stop when necessary
    • store objects in each leaf node

    Building BVH:

    如何划分？

    选择一个维度来划分。

    技巧1：纵切最长的轴来让最后比较均匀。 技巧2：取中间的物体，中间指的是一串物体排列下来，取中位数的物体，为的是保证物体划分均匀，最后树的深度小。

    这涉及到排序问题：如果我已经考虑好沿哪个轴切，那么物体重心沿该轴排序找中位数。但实际上有更快的不需要排序的方法。

    问题泛化：给定任意一列无序的数，要找到中位数，实际只要$O(n)$。

    Basic Radiometry 辐射度量学

    Motivation:

    为什么要提辐射度量学？

    在Blinn-Phong模型中，我们定义光强$I=10$，这个数字的单位是什么？物理意义是什么？

    还有，Whitted-Style生成的图片真实吗？

    辐射度量学能带来实际的精确的光的度量。

    Radiometry:

    定义了一系列方法和单位，描述光在空间中的性质，光照属性。

    • radiant flux
    • intensity
    • irradiance
    • radiance

    在物理上准确地定义光照。

    Radiant Energy and Flux (Power):

    定义：radiant energy是电磁辐射的能量，单位为焦耳$J$。$Q$

    定义：radiant flux (power)是单位时间的能量，单位是瓦特$W$。$\Phi=\frac{dQ}{dt}$ （描述光源的单位还能是$lm$）

    flux还能从另一个角度理解：一个平面单位时间内通过的光子数量。

    Important Light Measurements of Interest:

    Radiant Intensity:

    定义：每个单位立体角（solid angle）的功率

    $$I(w)=\frac{d\Phi}{dw}$$

    单位为$cd$，candela，七大标准单位之一。

    Angles and Solid Angles:

    角：$\theta=\frac{l}{r}$，在圆中为弧长和半径的比值。

    立体角是三维空间中的延伸：$\Omega=\frac{A}{r^2}$，在球中为面积和半径平方的比值。

    单位立体角：

    用$\theta$和$\phi$定义某个角度，图中的球面上的矩形的面积：

    $$dA=(rd\theta)(r\sin\theta d\phi)=r^2\sin\theta d\theta d\phi$$

    $$dw=\frac{dA}{r^2}=\sin\theta d\theta d\phi$$

    这个就是单位立体角。

    如果用$w$表示三维空间的方向，则对应的单位立体角就有了。

    Isotropic Point Source:

    $$\Phi=\int_{S^2}Idw=4\pi I$$

    其中$S^2$表示在球面上积分。
