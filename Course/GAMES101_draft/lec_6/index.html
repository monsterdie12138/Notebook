    Lec6 Rasterization2 (Antialiasing and Z-Buffering) 反走样和深度缓冲

    反走样：

    我们不想图像的锯齿太明显，锯齿的学名叫aliasing。

    Rasterization = Sample 2D Positions

    Photograph = Sample Image Sensor Plane

    Video = Sample Time

    Sampling Artifacts 采样瑕疵

    第一个问题就是锯齿 jaggies

    第二个问题就是摩尔纹 moire，例如去掉奇数行和奇数列，会出现一些奇怪的条纹。

    第三个问题就是车轮效应 wagon wheel effect，当车轮转动时，车轮的辐条会出现向前或者向后转动的错觉。（人眼在时间中的采样跟不上运动）

    根本原因是：信号变换过快，但采样过慢，速度跟不上。

    Antialiasing Idea:Blurring (Pre-Filtering) Before Sampling

    反走样的想法：在采样前先模糊（滤波）。

    例如将红色的三角形模糊，然后模糊的边界就是粉色（红色和白色的中间值）的。

    我能不能反过来，先采样再模糊处理？不能！！！

    Frequency Domain 频域：

    先考虑正弦和余弦函数：$\cos2\pi fx$

    $f=\frac{1}{T}$

    Fourier Transform 傅里叶变换：

    任何一个周期函数，都可以写成一系列三角函数组合+常数项。（傅里叶级数展开）

    傅里叶级数展开和傅里叶变换是密切相关的。

    Undersampling Creates Frequency Aliases:

    对于蓝色的线和黑色的线，如果我们按照图示频率进行采样，则得到的结果一样，这就是走样的真正定义。

    filtering = getting rid of certain frequency contents

    filter的作用就是去掉某些特定频率的内容。

    傅里叶变换将一个函数从时域变换到频域。

    右图表示频率，中间位置表示低频信号，数量多。

    高通滤波，去掉低频部分后，剩余的高频部分对应图像边缘。

    什么是边缘？两边差别很大，信号发生剧烈变化，对应高频信息。

    Convolution:

    从另一个角度来看：

    filter = convolution (averaging)

    时域上两个信号的卷积对应频域上的乘法。

    也就是说，在图片上直接做卷积是一种，先将图片傅里叶变换到频域，卷积核也做傅里叶变换，然后频域上做乘法，最后再做反傅里叶变换回到时域。这两种方法是等价的。

    Box Filter:

    Box Function = "Low Pass" Filter

    如果时域上的盒子变大（卷积核变大），则频域上的低频部分变多，高频部分变少，结果更加模糊，符合直觉。

    wider filter kernel = lower frequency

    sampling = repeating frequency contents

    采样实际上是在重复频域上的内容。

    Warning

    这里信号处理部分完全听不懂

    Antialiasing 反走样：

    方法一：增加分辨率（采样率），虚假的反走样

    方法二：真正的反走样

    先模糊再采样，模糊就是低通滤波，就是拿掉高频信息，再采样

    实际操作的滤波器：

    怎样将一个三角形变模糊？

    用一个低通滤波器进行卷积，以单个像素为单位，这个像素被三角形覆盖地越多，则这个像素的颜色越接近三角形的颜色。

    Antialiasing by Supersampling MSAA:

    究竟要怎么算覆盖区域？

    我们给出一种近似方法。

    对于任何一个像素，我认为这个像素内部还有多个采样点，每个采样点还能判断是否在三角形内，比率就可以估计为覆盖范围。

    注意：MSAA并没有真的提高分辨率，只是增加了采样点数。

    MSAA的缺点：

    增大了计算量

    其实还有其他抗锯齿的方法：FXAA（Fast Approximate Anti-Aliasing）和TAA（Temporal Anti-Aliasing）。
