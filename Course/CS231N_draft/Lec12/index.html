    Lec12 Visualizing and Understanding

    What is going on inside CNN?

    First Layer: Visualize Filters:

    They are looking for oriented edges and opposing colors. (not taking biases)

    Other Layers' Filters:

    We can directly visualize them as before, for the change of depth. For example, given a filter of $16\times 7\times 7$, we should lay it out to $16$ grayscale images of $7\times 7$.

    Not intuitive.

    Last Layer: FC:

    Input is a $4096$-dim vector (features), output is a $1000$-dim vector (scores).

    The last layer is doing nearest neighbor search in the feature space (semantic content instead of raw pixels).

    We can also visualize the last layer from a different perspective: Dimensionality Reduction

    algorithm: PCA or t-SNE

    Now we can apply this t-SNE to the feature vectors of images, which makes $4096$ dimension to $2$.

    Therefore, each image corresponds to a point in a 2D space, where similar images are closer together.

    Visualizing Activations (feature map):

    For example, this feature map is activating on the portion of human's face.

    Maximally Activating Patches:

    Pick a layer and a channel. Run many images through the network and record values of chosen channel. Visualize image patches that correspond to maximal activations.

    Occlusion Experiments:

    Mask part of the image before feeding to CNN, draw heatmap of probability at each mask location. If one part is masked and the result changes dramatically, then it implies that this part is important for the prediction, so we represents it as white color in the heatmap. (otherwise red)

    Saliency Maps:

    How to tell which pixels matter for classification? (similar to occlusion experiments)

    Compute gradient of (unnormalized) class score with respect to image pixels, take absolute value and max over RGB channels. To put it simply, for one pixel, we just modify it a little to see how the class scores change. That's where the gradient comes from.

    Gradient Ascent:

    梯度上升

    Normally we use gradient descent to update weights and achieve minimum loss. In this case, we want to maximize the class score, so we use gradient ascent instead, which does not change the weights but rather the input image itself.

    • Initialize image to zeros

    Repeat:

    • Forward image to compute current scores
    • Backprop to get gradient of neuron value with respect to image pixels

    Fooling images:

    梯度上升

    • Start from an arbitrary image
    • Pick an arbitrary class
    • Modify the image to maximize the class
    • Repeat until network is fooled

    DeepDream: Amplify Existing Features

    梯度上升

    Rather than synthesizing an image to maximize a specific neuron, instead try to amplify the neuron activations at some layer in the network.

    Note

    之前都是针对一个单独的filter，现在针对完整的一层。

    Choose an image and a layer in a CNN; repeat:

    • Forward: compute activations at chosen layer
    • Set gradient of chosen layer equal to its activation
    • Backward: compute gradient on image
    • Update image

    Feature Inversion:

    梯度下降

    Given a CNN feature vector for an image, find a new image that:

    • Matches the given feature vector
    • "looks natural" (image prior regularization)

    Now we still use gradient descent. We want to minimize the distance between feature vectors of given image and new image.

    The deeper CNN is, the more abstract the features become, making it harder to get our goal.

    Texture Synthesis:

    Given a sample patch of some texture, can we generate a bigger image of the same texture?

    We can use Gram Matrix.

    梯度上升

    Suppose we feed our texture image to CNN, and we choose one layer. This gives $C\times H\times W$ tensor of features. $H\times W$ grid of $C$-dimensional vectors.

    Outer product of two $C$-dimensional vectors gives $C\times C$ matrix measuring co-occurrence.

    Average over all $HW$ pairs of vectors, giving gram matrix of shape $C\times C$.

    Therefore, we can use the gram matrix as a goal. We should generate images that match this gram matrix.

    Neural Style Transfer:

    graph TD
    A[内容图像] --> C[预训练CNN<br>（如VGG19，权重冻结）]
    B[风格图像] --> C
    D[初始化生成图像] --> C

    C --> E[提取高层特征]
    C --> F[提取多层特征并计算Gram矩阵]

    E --> G[计算内容损失 Content Loss]
    F --> H[计算风格损失 Style Loss]

    G --> I{总损失<br>Total Loss = α·Content + β·Style}
    H --> I

    I -- 梯度 --> J[优化器<br>（更新生成图像像素）]
    J --> D

    K[循环迭代] --> I

    J -- 最终结果 --> L[风格迁移后的图像]

    Problem: style transfer requires many forward/backward passes.
