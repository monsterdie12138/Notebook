    采样

    下采样：隔像素采样

    aliasing：信号变化太快，采样频率太低

    采样时如何解决信号失真？

    提升采样频率，但很多时候给定的采样频率是固定的。

    数学上怎样描述信号变化快慢？

    对于周期信号，例如三角函数，周期越短，频率越高，变化越快。

    越高的频率需要越快的采样。

    失真例子见ppt。

    对于任意信号，不一定具有周期性。

    需要用到傅里叶变换。傅里叶变换的本质是把任意信号分解成不同频率的周期信号（三角函数）的叠加。

    例子见ppt，方波函数。

    每个周期信号前面都有系数，表示需要这个信号的多少。

    频谱就是右下角的直方图，见ppt。

    频谱每个频率对应的系数称为傅里叶系数。

    $f(x)$为原本信号，$F(u)$为频率为$u$的周期信号的傅里叶系数，离散的情况就像内积。

    因此这个式子就是在对$f(x)$和频率为$u$的周期信号做内积，算出$f(x)$在这个频率上的分量，即傅里叶系数，这就是傅里叶变换。

    逆变换：系数乘以对应的周期信号再求和（加权求和），就能还原出原本的信号。

    $\delta$为冲击信号，连续信号时表示无穷大，离散时不是。

    高斯函数的傅里叶变换还是高斯函数，只不过方差（宽度）变了。

    Convolution Theorem

    卷积定理：空间域（时域）上两个信号的卷积等于频域上两个信号的乘积，反之亦然。

    可通过傅里叶变换证明。

    卷积的另一种形式：先将两个信号分别做傅里叶变换，得到频域信号，然后将两个频域信号相乘，最后对乘积做逆傅里叶变换，得到的结果与空间域上两个信号直接卷积是一样的。

    回到图像上：

    二维的傅里叶变换与一维类似。

    二维图像的频谱是二维的直方图。

    中间表示频率为0，向外频率越来越高。

    如果是一维的频谱，每个位置代表一个频率；但二维的频谱，例如$(1,1)$是什么意思？沿着$x$轴频率为1，沿着$y$轴频率也为1，对应的值就是沿着$x$轴频率为1，沿着$y$轴频率为1的周期信号的系数（分量多少）。

    卷积核就像窗口函数，解释了频谱为什么长成这样。

    卷积去掉了高频成分，保留了低频成分，因此又叫滤波。

    窗口滤波器box filter = low-pass filter

    窗口越大，频谱中间的点越窄。

    再回到之前：sampling a signal = multiply the signal by a Dirac comb function

    就是乘以采样函数（脉冲函数）。

    脉冲函数傅里叶变换后还是脉冲函数，如果空间域的周期是$\Delta x$，那么频域的周期是$\frac{1}{\Delta x}$。

    因此采样是空间域的相乘，转换成频谱的卷积，假设采样函数频率为$f_s$，则频谱间隔（周期）为$f_s$。

    频谱像在复制。

    假设采样信号频率够高，则卷积后的频谱的峰间隔会比较大。否则峰会重叠，这时候频谱混叠，信号失真，无法还原原本图像的频谱。

    如果我希望采样后不发生失真，则$f_s$要大于$2f_0$，其中$f_0$为原本图像中最高频率。

    这个就是Nyquist-Shannon采样定理。

    频谱上的负的频率其实不用管，正负绝对值相等，只要关心绝对值就好了。

    因此，第二个减少走样的方法是改变原本信号的频谱，让原本信号的最高频率$f_0$降低，这个不是很要紧，因为一般图像都是低频成分多，高频成分少。

    也就是说，缩小图像前先进行低通滤波（模糊），去掉高频成分。

    Image Magnification

    把图像放大。

    放大要解决的是原本没有值的像素要怎么填。

    一般使用插值。

    插值就是给定某些位置的值，获得中间位置的值。

    最简单的插值是最近邻插值，如图，红点表示有值的地方，蓝色表示要插值的地方。

    问题：不连续、不光滑。

    连续：各个方向极限一致；光滑：一阶导连续

    更好一点的是线性插值，见ppt。

    连续但不光滑。

    多项式插值：每一段用一个高次多项式拟合，注意每一段的多项式不一样。

    要保证光滑至少需要三次多项式。

    绝大多数情况下线性插值就够了，线性插值要快很多。

    在二维空间上，双线性插值。

    上面两个点线性插值，得到中间点；下面两个点线性插值，得到中间点；再对这两个中间点线性插值，得到最终结果。

    还有二维空间中的三次多项式插值。

    现在还有超分辨率的技术，用深度学习的方法把图像放大。

    那么怎么改变长宽比？

    seam carving：扔掉不重要的像素，见ppt。

    不重要的像素一般周围像素差别不大，求导（边缘检测器），两个方向的导数加起来。

    但是比如每一行删掉一系列像素，如果扔掉的位置不同，可能会导致图像不齐。

    因此，每次每一行只能扔掉一个像素，要连起来，形成一条缝，因此叫seam carving。

    最短路径算法，动态规划。

    Model Fitting and Optimization

    数学上怎么定义一个优化问题？

    见ppt。

    $f_0(x)$，找到某个$x$使得$f_0(x)$最小，该函数称为目标函数。

    一些约束条件：$f_i(x)\leqslant 0$或$f_i(x)=0$。

    ppt的例子：$x$就是甲乙丙产品的数量，目标函数是利润，约束条件是资源限制。

    Model Fitting

    模型拟合：数学上的模型就是函数，函数描述了输入和输出的关系$b=f_x(a)$。

    $f$可能不知道。根据大量观测到的数据选择合适的参数拟合。

    如何得到参数？也是写成优化问题。

    优化的目标函数是Mean Squared Error (MSE)。

    最大似然估计：在给定观测数据的情况下，选择参数使得观测数据出现的概率最大化。

    那么怎么求解MSE优化问题：$\min||Ax-b||_2^2$

    $A=\begin{pmatrix} a_1^T\ a_2^T\ ...\ a_n^T \end{pmatrix}$

    $b=\begin{pmatrix} b_1\ b_2\ ...\ b_n \end{pmatrix}$

    导数为0，$||Ax-b||_2^2$对$x$求导，得到$A^T(Ax-b)=0$，即$A^TAx=A^Tb$。

    Numerical Methods

    数值优化，初始化，找到下降方向，找到步长，更新，迭代。

    要使用泰勒展开。

    一阶近似：$F(x_k+\Delta x)\approx F(x_k)+J_F\Delta x$

    $\Delta x$的几次就是几阶展开。

    $J=(\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, ..., \frac{\partial f}{\partial x_n})$

    二阶近似：$F(x_k+\Delta x)\approx F(x_k)+J_F\Delta x+\frac{1}{2}\Delta x^TH_F\Delta x$

    $H_F$为Hessian矩阵。

    相当于曲面近似。

    如何确定最优下降方向？

    给$\Delta x$确定一个方向，使得目标函数下降最快，当$\Delta x$和$J_F$的方向相反时，下降最快。

    这种方法称为最速下降法。

    确定方向后，如何确定步长？

    步长太小走得太满，步长太大不符合泰勒公式，容易振荡。

    经常动态调整。

    变成新的函数，$\phi(\alpha)=F(x_0+\alpha h)$，穷举法。

    常用backtracking，先用一个比较大的步长，然后逐渐减小，例如每次缩小一半，直到满足：$\phi(\alpha)\leqslant\phi(0)+\gamma\phi'(0)\alpha$。

    如ppt所示，就是落到绿色区间内，说明找到了一个比较好的步长。

    最速梯度的好处：容易实现，但是迭代到谷底附近时收敛很慢。

    怎么办？接近谷底时使用牛顿法-二阶泰勒展开。

    $$H_F\Delta x+J_F^T=0$$

    最佳下降方向$\Delta x=-H_F^{-1}J_F^T$

    因此：一阶：最速梯度下降法 二阶：牛顿法

    牛顿法在谷底效果很好。

    牛顿法的缺点：海森矩阵计算量大，求逆更是复杂。

    高斯牛顿法对牛顿法进行近似。

    很多时候目标函数都是MSE，即平方和形式。

    高斯牛顿法并不是对整个目标函数进行泰勒展开，而是对$||R(x)||_2^2$中的$R(x)$进行一阶泰勒展开。

    见ppt。得到高斯牛顿法的下降方向。

    实际上$J_R^TR(x_k)=J_F^T$

    高斯牛顿法有时候那个值不是满秩的，会得到无穷多个解。很多时候会加上一个正则项$\lambda I$，称为Levenberg-Marquardt算法。

    开始时$\lambda$比较大，接近梯度下降法，接近谷底时$\lambda$变小，接近牛顿法。
